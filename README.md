# 自主活动 0.2.0

为角色提供独立的、可恢复的自主活动会话。定时器随机安排下一次检查，按峰谷、最近 QQ 活动、没中加成、冷却、每日次数和活动安静时段决定是否唤醒。唤醒后角色自己选择行动或结束。DSH 停止期间不运行；随机检查不调用模型，实际唤醒会消耗模型 token。

角色可以在已接入的聊天或自主活动中保存自己想做的事，包括想法的来源、相关对象、下次考虑时间和后续结果。想法可以延期、等待、结束或取消；保存不等于立即执行，到期不等于必须行动。角色也可以记下真实探索中发现的应用、网站、文件、游戏和聊天入口，使用前重新核对位置与现有权限。入口记录本身不授予权限，不会自动打开应用或发送消息。

自主活动会补充近期经历、相关人物、尚未完成的计划和重要关系记忆，并带上待考虑的想法。来源仍受人格、预演状态和私密范围限制；私人来源不因为整理为想法就变成可对外转述的信息。此过程不需要为每一条聊天另调一个模型。角色可以选择已有想法，也可以产生新兴趣或休息，不以固定剧情触发特定行动。

自主活动可以查询已接入且未暂停的群，并提出去群聊的意图；目标群会话结合已有上下文决定是否发言。自主联系遵守 QQ 安静时段、每小时联系上限和同群 10 分钟冷却；待处理的群消息优先。不会自动重放结果不确定的联系，私密来源不能转到群里。

默认：随机检查间隔 20–40 分钟；峰时命中线 20%、谷时 60%；没中每次加 10 个百分点、最多加 40；冷却 30 分钟、每天最多 8 次自动唤醒。峰时默认周一至周五 9–12、14–18；活动安静 1–8 点，主动 QQ 安静 23–8 点。均以本机时间判断，可在设置页修改。手动唤醒不受每日上限，但仍受活动安静时段约束。

相关事件与到期想法可提供额外的活动机会，默认启用，事件等待时间默认 3 分钟。这些机会仍受暂停、活动安静时段、冷却、每日上限和结果待核实状态约束。一次到期提醒被考虑后不会一直重复唤醒；需要继续时由角色重新安排。设置页可以推迟一小时或取消想法的后续提醒，不会撤回已经发生的操作。

每轮活动默认有 10 分钟和 40 次工具调用预算。预算用于限制继续发起操作，不会把未完成的事情标成成功，也不能撤销已经发生的外部效果。现有工具权限仍然有效。用户操作电脑时应避让，不能依靠保存的计划绕过应用、账号或发送渠道的授权。

角色工作目录、模型、预设、人格文件、角色标识、预演状态取自 QQ 插件现有配置。自主活动有自己的 DSH 会话和 `local:activity` 聊天身份；自动加载原有记忆和情绪工具及状态。私人来源保持原范围，不能自动跨聊天传递。角色可用 `nia_observations` 引用真实工具回执并保存有证据的自身经历；本轮新增的这类回执会交给情绪插件评估，可能额外调用模型。没有新的回执则不触发额外评估；普通操作不会被自动写成长久记忆。

`nia_activity_contact` 可选地向已认识的人发起 QQ 联系意图，目标私聊自主决定是否发送。提供的事件来源必须对目标会话可见；无来源时只转达“想找对方聊聊”，不转发自由填写的原因。目标不存在、暂停、用户要求停止主动联系、QQ 安静时段、演练模式均不会主动发信。QQ 消息正在排队时先处理新消息，明确停止会取消未处理的活动联系。QQ 目标会使用当前的私聊绑定，因此会话续接后不需要重新勾选 ID。

活动任务使用持久化状态：启动、接受和恢复不确定的结果不会自动重放；可在界面核实后解除阻塞。旧会话文件不存在时拒绝静默新建。设置、活动日志与 `notebook.json` 在 DSH_HOME/nia-activity；迁移时需要连同 DSH 会话、QQ/记忆/情绪数据及人格文件一起迁移。保留已有会话和计数，不需要重置记忆。

设置页展示“想做的事”“已认识的入口”“最近活动结果”和工具状态。工具清单只说明 DSH 已登记哪些工具；没有模型请求证据时，不把它显示为已确认发送给模型。工具回执与角色的进展记录分别看待，本轮结束不表示全部计划完成。桌面自动化仍依赖当前预设实际提供的工具，插件不自带一条绕过工具权限的电脑控制通道。

“仅演练”命中仅写记录，不运行模型或发 QQ；独立的手动唤醒按钮会真实调用当前配置模型。关闭自主活动时，已经开始的当前轮正常结束，尚未发出的自主联系会等待重新启用。除本插件的 QQ 联系工具之外，其他预设工具仍受现有权限规则控制。

需要配套支持自主活动上下文与会话扩展的角色记忆插件、情绪 0.4.0 和具备 niaQQ 服务的 QQ 0.5.1。原 dsh-speak-up 可以保留停用，避免重复唤醒。

开发验证使用隔离数据和模拟工具，不以真实 QQ、微信或 Codex 发信作为测试。通过本地测试不能替代重启 DSH 后对模型实际工具请求与真实桌面操作的核验。
